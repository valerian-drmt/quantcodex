# QuantCodex

A codex for quantitative finance: solve quant problems and brainteasers, look up the theory in research notebooks, and study probability games and game theory step by step.

**Open the site:** https://valerian-drmt.github.io/quantcodex/

Nothing to install and no account needed: everything is read in the browser.

## What you will find

| Section | What it is | Status |
|---|---|---|
| [Problems](https://valerian-drmt.github.io/quantcodex/problems/) | Brainteasers and problems in probability, statistics and finance, each with a hint, the answer and a worked explanation | Being rebuilt |
| [Research notebooks](https://valerian-drmt.github.io/quantcodex/notebooks/) | Notes on pricing, machine learning, microstructure and trading, with their formulas, code and outputs | Template only for now |
| [Game modelling](https://valerian-drmt.github.io/quantcodex/games/) | Probability games and game theory: rules, exact expected value or equilibrium, and the proof behind the optimal strategy | Coming next |

## How to use it

### Problems

- Pick a problem from the list. Narrow it down by category and difficulty (Easy, Medium, Hard), search for a term, or sort by number, title or difficulty.
- Each problem page starts a timer that you can pause, so you can train under interview conditions.
- The hint, the answer and the explanation stay folded until you open them. Open them in that order: try the problem first, take the hint if you are stuck, check your result against the answer, then read the explanation.
- Previous and Next move through the problems in number order.

### Research notebooks

- Filter the list by domain to find a topic.
- Each notebook has a contents sidebar that follows its headings.
- Code cells can be hidden with one button if you only want the maths and the results.

### Game modelling

Each game will be treated end to end: the rules, the exact expected value or the equilibrium, and the proof of the optimal strategy.
